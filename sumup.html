SumUp einrichten (Start)

Ist SumUp eingerichtet, erscheinen in der Kasse „Karte“ und „Betrag“. Nach „Zugang löschen“ (unten) sind sie wieder weg.

Per QR einrichten

Auf dem PC diese Seite öffnen, unten „QR für Tablet erstellen“. Dann hier scannen.

Solo koppeln

Solo abmelden, dann Menü → Verbindungen → API → Verbinden. Code innerhalb von 5 Min. eingeben.

Solo wählen

QR für Tablet erstellen

Am PC: Key aus dem SumUp-Dashboard einfügen, Solo wählen, QR anzeigen, mit dem Tablet scannen. Hier wird nichts gespeichert – nach Neuladen ist alles weg.
Der QR enthält den API-Key: nur dem Tablet zeigen, danach „Leeren“.

Zugang von Hand

Wird nur auf diesem Gerät gespeichert (localStorage), nie hochgeladen. Ein gespeicherter Key wird nicht mehr angezeigt; Feld leer lassen = behalten.
